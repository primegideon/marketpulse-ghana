# 30-Day Price Projections

Forward price projections generated by a Meta Prophet time-series model trained on WFP historical price data. Each forecast includes an 80% confidence interval and is benchmarked against a naive baseline (last known value) to assess model reliability.

```sql forecast_commodities
SELECT DISTINCT commodity_name
FROM agri_ghana.fact_price_forecasts
WHERE is_forecast = TRUE
ORDER BY commodity_name
```

```sql forecast_series
SELECT
    record_date,
    ROUND(predicted_price_ghs, 2)  AS predicted_price_ghs,
    ROUND(lower_bound_ghs, 2)      AS lower_bound_ghs,
    ROUND(upper_bound_ghs, 2)      AS upper_bound_ghs,
    is_forecast
FROM agri_ghana.fact_price_forecasts
WHERE commodity_name = '${inputs.selected_commodity.value}'
ORDER BY record_date
```

```sql forecast_kpis
SELECT
    ROUND(predicted_price_ghs, 2)           AS next_month_price,
    ROUND(lower_bound_ghs, 2)               AS lower_bound,
    ROUND(upper_bound_ghs, 2)               AS upper_bound,
    ROUND(upper_bound_ghs - lower_bound_ghs, 2) AS confidence_range,
    ROUND(mape_score, 1)                    AS model_mape,
    ROUND(baseline_mape_score, 1)           AS baseline_mape
FROM agri_ghana.fact_price_forecasts
WHERE commodity_name = '${inputs.selected_commodity.value}'
  AND is_forecast = TRUE
ORDER BY record_date
LIMIT 1
```

```sql all_forecasts_table
SELECT
    commodity_name,
    record_date,
    ROUND(predicted_price_ghs, 2)  AS predicted_price_ghs,
    ROUND(lower_bound_ghs, 2)      AS lower_bound_ghs,
    ROUND(upper_bound_ghs, 2)      AS upper_bound_ghs,
    ROUND(mape_score, 1)           AS model_mape,
    ROUND(baseline_mape_score, 1)  AS baseline_mape
FROM agri_ghana.fact_price_forecasts
WHERE is_forecast = TRUE
ORDER BY commodity_name, record_date
```

> **Model accuracy:** MAPE (Mean Absolute Percentage Error) measures average forecast error as a percentage. The Prophet model is compared against a naive baseline — simply repeating the last known price. A lower Prophet MAPE than baseline confirms the model adds predictive value beyond the simplest possible guess.
