# Maize Price Forecasts

> **XGBoost 3-Month Forward Projection**: Predicted wholesale Maize prices (GHS/KG) using a walk-forward cross-validated XGBoost model trained on 17 years of WFP market data. Historical actuals are stitched seamlessly to the 3-month forward projection.

---

```sql stitched_series
SELECT
    date,
    median_price_ghs_per_kg      AS actual_price,
    CAST(NULL AS DOUBLE)         AS forecast_price,
    CAST(NULL AS DOUBLE)         AS lower_ci,
    CAST(NULL AS DOUBLE)         AS upper_ci,
    'Historical Actual'          AS series_type
FROM agri_ghana.mart_commodity_monthly
WHERE commodity = 'Maize'
  AND raw_unit = '100 KG'
  AND price_type = 'Wholesale'
  AND median_price_ghs_per_kg IS NOT NULL

UNION ALL

SELECT
    target_date                  AS date,
    CAST(NULL AS DOUBLE)         AS actual_price,
    predicted_price_ghs_per_kg   AS forecast_price,
    lower_ci_95                  AS lower_ci,
    upper_ci_95                  AS upper_ci,
    'Projected Forecast'         AS series_type
FROM agri_ghana.mart_maize_forecasts
WHERE commodity = 'Maize'
ORDER BY date ASC
```

```sql forecast_table
SELECT
    target_date,
    horizon_months,
    ROUND(predicted_price_ghs_per_kg, 4) AS predicted_price_ghs_per_kg,
    ROUND(lower_ci_95, 4)                AS lower_ci_95,
    ROUND(upper_ci_95, 4)                AS upper_ci_95,
    forecast_date,
    model_version
FROM agri_ghana.mart_maize_forecasts
WHERE commodity = 'Maize'
ORDER BY horizon_months
```

```sql latest_actual
SELECT
    date,
    ROUND(median_price_ghs_per_kg, 4) AS latest_actual_ghs_per_kg,
    markets_reporting
FROM agri_ghana.mart_commodity_monthly
WHERE commodity = 'Maize'
  AND raw_unit = '100 KG'
  AND price_type = 'Wholesale'
  AND median_price_ghs_per_kg IS NOT NULL
ORDER BY date DESC
LIMIT 1
```

```sql one_month_forecast
SELECT
    ROUND(predicted_price_ghs_per_kg, 4) AS predicted_ghs_per_kg,
    ROUND(lower_ci_95, 4)                AS lower_ci,
    ROUND(upper_ci_95, 4)                AS upper_ci
FROM agri_ghana.mart_maize_forecasts
WHERE commodity = 'Maize' AND horizon_months = 1
```

### Model Architecture

This forecast is generated by a **tuned XGBoost Regressor** trained using walk-forward time-series cross-validation on 17 years (2006–2023) of WFP Ghana maize price data.

| Property | Value |
|---|---|
| Algorithm | XGBoost Regressor |
| Training data | WFP HDX Ghana, 2006–2023 (Wholesale, 100 KG sack) |
| Cross-validation | Walk-forward (9 folds, 60-month min train, 12-month horizon) |
| CV RMSE (log space) | 0.09948 |
| Naive baseline RMSE | 0.6302 GHS/KG |
| Train RMSE | 0.0216 GHS/KG |

### Feature Set (16 features)

| Feature Group | Features |
|---|---|
| Lag features (log-space) | `log_lag_1`, `log_lag_2`, `log_lag_3`, `log_lag_6`, `log_lag_12` |
| Rolling means (log-space) | `log_roll_mean_3`, `log_roll_mean_6`, `log_roll_mean_12` |
| Rolling volatility | `roll_std_3` |
| Calendar / seasonal | `month_sin`, `month_cos`, `quarter`, `year` |
| Momentum | `pct_change_1m`, `pct_change_12m` |
| Market breadth | `n_markets` |

### Confidence Intervals

95% CI bounds are estimated as ±1.96 × 12% of the point forecast (conservative, based on walk-forward CV residuals). Intervals widen for horizons 2–3 months ahead.

### Retraining Triggers

Per `INFERENCE_PROTOCOL.md`, the model should be retrained when:
- Rolling 3-month MAPE exceeds **15%**
- Year-over-Year national food inflation exceeds **40%** (regime shift)

Scheduled retraining: bi-annually after Major Harvest (August) and Minor Season (November) data syncs.
